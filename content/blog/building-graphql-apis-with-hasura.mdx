# Building GraphQL APIs with Hasura

Hasura has transformed how I build backend APIs. It provides instant GraphQL APIs over PostgreSQL with real-time subscriptions and fine-grained access control.

## Why Hasura?

After building numerous APIs, here's why I choose Hasura:

- **Instant API**: Generate GraphQL API from your database
- **Real-time**: Built-in subscriptions for live data
- **Authorization**: Row-level security with permissions
- **Performance**: Optimized query batching and caching

## Getting Started

Setting up Hasura is straightforward:

```yaml
# docker-compose.yml
version: '3.6'
services:
  postgres:
    image: postgres:15
    environment:
      POSTGRES_PASSWORD: postgrespassword
  hasura:
    image: hasura/graphql-engine:latest
    ports:
      - "8080:8080"
    environment:
      HASURA_GRAPHQL_DATABASE_URL: postgres://postgres:postgrespassword@postgres:5432/postgres
      HASURA_GRAPHQL_ENABLE_CONSOLE: "true"
```

## Designing Your Schema

Start with a clean database schema:

```sql
CREATE TABLE users (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  email TEXT UNIQUE NOT NULL,
  name TEXT NOT NULL,
  created_at TIMESTAMPTZ DEFAULT now()
);

CREATE TABLE posts (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  title TEXT NOT NULL,
  content TEXT,
  author_id UUID REFERENCES users(id),
  published BOOLEAN DEFAULT false,
  created_at TIMESTAMPTZ DEFAULT now()
);
```

## Setting Up Permissions

Hasura's permission system is powerful:

```json
{
  "role": "user",
  "table": "posts",
  "operation": "select",
  "permission": {
    "filter": {
      "_or": [
        { "published": { "_eq": true } },
        { "author_id": { "_eq": "X-Hasura-User-Id" } }
      ]
    }
  }
}
```

```graphql
type Mutation {

```

Then implement the handler in your preferred language.

## Performance Tips

From production experience:

1. **Use query caching** for frequently accessed data
2. **Optimize relationships** - avoid N+1 queries
3. **Index your columns** - especially for filters
4. **Monitor slow queries** using Hasura's metrics

## Conclusion

Hasura accelerates API development without sacrificing flexibility. It's become an essential tool in my stack for building modern applications.
