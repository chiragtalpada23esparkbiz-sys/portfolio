# Optimizing Next.js Performance

Performance is crucial for user experience and SEO. In this guide, I'll share strategies I use to achieve excellent Core Web Vitals scores in Next.js applications.

## Understanding Core Web Vitals

Google's Core Web Vitals consist of three metrics:

- **LCP (Largest Contentful Paint)**: Should be under 2.5 seconds
- **FID (First Input Delay)**: Should be under 100 milliseconds
- **CLS (Cumulative Layout Shift)**: Should be under 0.1

## Image Optimization

Next.js provides built-in image optimization. Here's how to use it effectively:

```tsx
import Image from 'next/image';

function HeroImage() {
  return (
    <Image
      src="/hero.jpg"
      alt="Hero image"
      width={1200}
      height={630}
      priority // Load above-the-fold images immediately
      placeholder="blur"
      blurDataURL="data:image/jpeg;base64,..."
    />
  );
}
```

## Font Optimization

Use Next.js font optimization to prevent layout shift:

```tsx
import { Inter } from 'next/font/google';

const inter = Inter({
  subsets: ['latin'],
  display: 'swap',
  variable: '--font-inter',
});
```

## Code Splitting

Implement dynamic imports for heavy components:

```tsx
import dynamic from 'next/dynamic';

const HeavyComponent = dynamic(
  () => import('@/components/HeavyComponent'),
  {
    loading: () => <Skeleton />,
    ssr: false, // Disable SSR if not needed
  }
);
```

## Server Components

Leverage React Server Components to reduce client-side JavaScript:

```tsx
// This runs on the server - no JavaScript sent to client
async function DataDisplay() {
  const data = await fetchData();
  return <div>{data.title}</div>;
}
```

## Caching Strategies

Implement proper caching for better performance:

```tsx
// In next.config.ts
const nextConfig = {
  headers: async () => [
    {
      source: '/static/:path*',
      headers: [
        {
          key: 'Cache-Control',
          value: 'public, max-age=31536000, immutable',
        },
      ],
    },
  ],
};
```

## Measuring Performance

Use these tools to measure and monitor:

1. **Lighthouse** - Built into Chrome DevTools
2. **PageSpeed Insights** - Google's online tool
3. **Web Vitals** - Real user monitoring library

## Conclusion

Performance optimization is an ongoing process. Regularly measure, identify bottlenecks, and iterate. Your users (and Google) will thank you!
